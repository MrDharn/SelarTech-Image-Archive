# SELARTECH ARCHIVE

A full-stack MERN application for managing and viewing image archives.

SELARTECH ARCHIVE allows authenticated users to browse uploaded images while administrators can upload, edit, and delete images. Images are stored securely on Cloudinary, and authentication is handled using JWT.

---

## Features

### Authentication & Authorization

- User Registration
- User Login
- JWT Authentication
- Protected Routes
- Role-Based Access Control
- Admin and User Roles

### Image Management

- Upload Images (Admin Only)
- View All Images
- Delete Images (Admin Only)
- Cloudinary Image Storage
- Image Metadata Storage in MongoDB

### User Interface

- Responsive Design
- Loading States
- Protected Dashboard
- Admin Dashboard Controls
- Login and Signup Navigation
- Modern Gallery Layout
